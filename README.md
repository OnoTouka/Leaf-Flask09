# Leaf&Flask

## ゲーム説明

植物などのアイテムを集めながら探索を進める2D探索ゲームです。

SPを消費して探索を行い、探索を進めることで入手できるアイテムが増えていきます。

探索中には敵との戦闘も発生し、HPを管理しながら探索を続けます。

ゲーム終了時には、そのゲームで獲得したアイテムと個数を確認できます。

## Unity Version

Unity 6.3.21f1

## 操作方法

- マウス：ボタンやアイテムをクリック
- Space：攻撃

## 使用素材・ライセンス

### イラスト

- ゲーム内で使用しているイラストは、友人が制作したものを使用しています。

- 効果音：効果音ラボ

各音源は、それぞれの配布元が定める利用規約・ライセンスに従って使用しています。
